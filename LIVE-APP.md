# Live app

[Open R2 Pickup Day](https://rivian-r2-pickup.stable-lemur-0275.chatgpt.site)

The app is private. Use the same ChatGPT account on every device, then enter the last four VIN characters to reopen your inspection. On iPhone Safari, use Share → Add to Home Screen for an app icon.

This repository contains source code. Full VINs, inspection notes and saved results belong to the private application database and are not committed here.
